## During the Interview

### Do's
- Listen to the full question before answering
- Think for 3-5 seconds before responding
- Structure answers: Context -> Approach -> Implementation -> Trade-offs
- Be honest about what you don't know
- Ask clarifying questions for system design
- Show your thought process while solving DSA
- Connect answers to your real project experience

### Don'ts
- Don't rush answers
- Don't memorize answers word-for-word
- Don't say "I don't know" immediately - think first
- Don't badmouth previous companies/internships
- Don't lie about metrics or experience
- Don't interrupt the interviewer

### Power Phrases
- "In my LawPrix project, I faced a similar challenge where..."
- "The approach I'd take is... and here's why"
- "I haven't implemented this yet, but here's how I would approach it"
- "A trade-off I considered was..."

## Emergency Quick Revision (5 min before)

### OOP - SOLID Mnemonic
- **S**ingle Responsibility - One class, one job
- **O**pen/Closed - Open for extension, closed for modification
- **L**iskov Substitution - Subtypes must be substitutable
- **I**nterface Segregation - Many specific interfaces > one general
- **D**ependency Inversion - Depend on abstractions, not concretions

### DBMS - Query Execution Order
`FROM -> WHERE -> GROUP BY -> HAVING -> SELECT -> ORDER BY -> LIMIT`

### DSA - Pattern Recognition
- Sorted array + search target -> **Binary Search**
- Subarray sum/subarray with condition -> **Sliding Window**
- All subsets/permutations -> **Backtracking**
- Optimal substructure + overlapping subproblems -> **Dynamic Programming**
- Shortest path -> **BFS (unweighted) / Dijkstra (weighted)**
- Topological order needed -> **DFS on DAG**

### Python - Big O Common
- List index access: O(1)
- List append: O(1) amortized
- List search: O(n)
- Dict lookup: O(1) average
- String concatenation: O(n)
- Sorting: O(n log n)
