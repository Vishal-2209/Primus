## Infosys-Specific Tips

### Online Test Pattern
- **Aptitude**: 15-20 questions, 25 minutes
- **Coding**: 2-3 problems, 45 minutes
- **Difficulty**: Easy to Medium (LeetCode Easy/Medium)

### Technical Interview Focus
1. **DSA**: 1-2 coding problems (explain approach + write code)
2. **OOP**: SOLID, Design Patterns (Singleton, Factory)
3. **DBMS**: SQL queries (joins, window functions, subqueries)
4. **Projects**: End-to-end walkthrough of LawPrix/PGPulse/Nexus
5. **Basics**: OS (process vs thread), Networking (TCP/IP, REST)

### Time Allocation (45 min coding test)
- Problem 1 (Easy): 10 min
- Problem 2 (Easy-Medium): 15 min
- Problem 3 (Medium): 20 min

## Quick Pattern Recognition

```
"Find pair with sum"           -> Two Pointer or HashMap
"Find subarray with sum"      -> Sliding Window or Prefix Sum
"Find longest/shortest"       -> Sliding Window or DP
"Find in sorted array"        -> Binary Search
"Process level by level"      -> BFS
"Find all paths/combos"       -> Backtracking
"Optimal substructure"        -> Dynamic Programming
"Minimum operations"          -> BFS or DP
```
